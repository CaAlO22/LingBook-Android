# 2.1.0

> 本文件是「当前未发布版本」的更新日志源。版本号取自上面的标题，必须与
> `app/build.gradle.kts` 的 `versionName` 一致；发版前由 agent 或人手动重写，
> 然后执行 `python tools/gen_changelog.py` 生成 `app/src/main/res/raw/changelog.json`。
> 已发布版本的历史日志由脚本从 GitHub Release 抓取，不需要写在这里。

## 新功能

- 待办列表支持拖动排序：每条左侧新增拖动手柄，按住即可上下拖动调整顺序，拖到列表上下边缘会自动滚动，长列表也能一口气拖到底
- 长按待办或碎片可复制正文，复制后提示「已复制到剪贴板」
- 新增「历代更新日志」：设置 → 应用栏可查看 v1.0.0 以来每个版本改了什么，内容随安装包内置，离线可查
- 更新源支持填写自己的访问令牌：设置里可分别配置 GitHub Token 与 Gitee Token，支持显示/隐藏与一键清除，缓解匿名访问被限流
- 云同步拆分为三个独立开关：云同步笔记、云同步模型配置、云同步访问令牌，不想同步某一类时关掉即可

## 优化

- 云同步按类别生效：关闭的类别不再推送、也不再应用远端变更；重新开启时会自动做一次全量拉取，补齐关闭期间其他设备产生的内容
- 手势返回的收缩终点改由手指推动方向决定，拖动只消耗时间轴前半程，松手后自然收尾，不再一路冲到底
- Gitee 检查更新被限流时自动改走网页跳转取版本号，不再直接报「检查更新失败」
- 删除待办前增加二次确认，避免误删
- 新增待办后列表自动滚动到底部，刚加的条目立刻可见
- 弹窗内聚焦输入框不再被输入法遮挡或上下跳动，分屏与小窗下同样适用
- 设置页「导入 .ling 文件」与「从剪贴板导入」改为并排显示，省下一行高度

## 修复

- 修复待办排序不生效：顺序此前只跟随创建时间，现在按位次排序，新条目追加到末尾
- 修复填写无效或过期 Token 时检查更新只提示笼统的 HTTP 错误，现在会明确提示「Token 无效或已过期」，并指向设置页
- 修复小窗（自由窗口）中弹窗聚焦输入框时页面上下跳动，滚动只发生在弹窗正文区
- 修复云同步只同步了一半内容的问题：开关关闭期间不再重复推送，重新开启后补齐数据

## 数据库升级

- 数据库升级至 v21：待办表新增排序位次列，升级时按原创建时间自动补齐，旧数据升级后顺序保持不变
