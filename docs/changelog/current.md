# 2.5.0

> 本文件是「当前未发布版本」的更新日志源。版本号取自上面的标题，必须与
> `app/build.gradle.kts` 的 `versionName` 一致；发版前由 agent 或人手动重写，
> 然后执行 `python tools/gen_changelog.py` 生成 `app/src/main/res/raw/changelog.json`。
> 已发布版本的历史日志由脚本从 GitHub Release 抓取，不需要写在这里。

## 新功能

- 文件夹支持嵌套：可以在文件夹内继续新建子文件夹，逐级打开查看
- 文件夹内的笔记与子文件夹共用一套排序，支持长按拖拽调整顺序
- 拖拽笔记或文件夹到文件夹卡片上即可移入；文件夹菜单新增「移出文件夹」与「解散」
- 文件夹卡片同时显示笔记数与子文件夹数

## 优化

- 首页与文件夹页统一了拖拽排序体验：插入位置有明确标记，首位之前和末位之后都能插入，横竖屏切换也不会错位
- 删除文件夹改为连同其中的全部笔记与子文件夹一起删除，并给出明确提示；只想保留笔记时请使用「解散」
- Markdown 恢复常规解析：编辑时留下的空行会在预览和 PDF 导出中按标准 Markdown 渲染为段落间隔，不再被自定义规则折叠
- 云同步协议升级以支持文件夹嵌套；使用自建同步服务端时请一并更新服务端程序

## 修复

- 修复纯表格碎片在碎片列表中显示为空白的问题
- 修复含空行的笔记在预览、PDF 导出中段落粘连的问题

## 数据库升级

- 文件夹表新增父文件夹字段以支持嵌套，升级时自动迁移，原有数据保持不变
