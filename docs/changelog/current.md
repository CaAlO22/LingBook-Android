# 2.3.0

> 本文件是「当前未发布版本」的更新日志源。版本号取自上面的标题，必须与
> `app/build.gradle.kts` 的 `versionName` 一致；发版前由 agent 或人手动重写，
> 然后执行 `python tools/gen_changelog.py` 生成 `app/src/main/res/raw/changelog.json`。
> 已发布版本的历史日志由脚本从 GitHub Release 抓取，不需要写在这里。

## 新功能

- 待办提醒：每条待办都能单独设置提醒；一次性待办选日期和时间，重复待办只需选当天时刻，日期自动跟随重复规则，触发后自动排到下一周期
- 待办列表提醒：右上角菜单可设置整个列表的提醒，刷新前还有未完成待办时提醒，避免漏做每日委托
- 创建待办列表时必须先选择重复规则（一次性 / 每日 / 工作日 / 休息日 / 间隔 / 自定义），创建后不可修改；取消则放弃创建
- 首页聚合页：集中查看所有待办列表的未完成待办与尚未归入笔记的碎片；可在「设置」中选择默认打开卡片列表还是聚合页
- 聚合页待办按提醒时间排序：提醒越近越靠前，未设置提醒的排在最后，同一提醒时间按录入时间排序
- 云端模型目录：模型列表可由服务端统一下发，新增或调整模型无需更新 App；同步设置中显示模型列表版本并可手动刷新
- 新建或切换模型配置时默认开启深度思考，优先 HIGH 档，模型不支持时自动取次高档

## 优化

- 待办输入框加高到四行并支持滚动，输入长待办不再局促；输入框内可直接设置提醒，也可在待办条目的编辑弹窗中修改
- 待办列表的提醒与重复规则收进右上角菜单，不再占用列表显示空间
- 长按选取笔记正文时不再弹出输入法，选字时键盘不会遮挡正在编辑的内容
- 云同步加入协议版本校验：服务器过旧时明确提示并停止同步，避免「提示同步成功但数据丢失」
- AI 助手的待办工具同步升级：可读取和设置单条待办与整个列表的提醒；重复规则只能在创建待办笔记时指定，避免误改
- 各供应商的思考档位默认值规则统一，新建配置的表现保持一致

## 修复

- 修复 AI 助手读取待办笔记时看不到重复规则、容易把上一周期的勾选当成已完成的问题
- 修复待办列表底部的输入区域会遮挡最后一条待办的问题

## 数据库升级

- 数据库版本升级到 23：新增待办与待办列表的提醒字段、首页默认落地页设置；升级自动完成，历史笔记与待办不受影响
