# 2.4.0

> 本文件是「当前未发布版本」的更新日志源。版本号取自上面的标题，必须与
> `app/build.gradle.kts` 的 `versionName` 一致；发版前由 agent 或人手动重写，
> 然后执行 `python tools/gen_changelog.py` 生成 `app/src/main/res/raw/changelog.json`。
> 已发布版本的历史日志由脚本从 GitHub Release 抓取，不需要写在这里。

## 新功能

- 云同步新增「数据管理」：可用本机数据覆盖云端，也能从云端恢复，支持覆盖本地与合并本地两种模式
- 同步服务器内置网页管理台：在浏览器打开服务器地址即可查看数据概览，浏览、搜索云端实体与墓碑，删除单条记录或清空整张表
- 接入系统分享：可把其他应用里的文字、链接或图片直接分享到灵记
- 待办列表菜单新增「自动排序」：勾选完成的待办自动沉底，取消完成后回到原位
- 首页对话里记录的碎片支持编辑，修改后保留原始记录时间

## 优化

- 碎片笔记的碎片气泡宽度至少占屏幕宽度的 70%，宽屏设备上显示更舒展

## 数据库升级

- 数据库升级至 v24（补充同步所需结构），升级后本地数据保持不变
