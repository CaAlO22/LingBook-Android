# 2.2.0

> 本文件是「当前未发布版本」的更新日志源。版本号取自上面的标题，必须与
> `app/build.gradle.kts` 的 `versionName` 一致；发版前由 agent 或人手动重写，
> 然后执行 `python tools/gen_changelog.py` 生成 `app/src/main/res/raw/changelog.json`。
> 已发布版本的历史日志由脚本从 GitHub Release 抓取，不需要写在这里。

## 新功能

- 内置 AI 助手现在能直接管理待办笔记：新增、勾选、改文字、删除单条待办，改完立刻能在笔记里看到
- 新建笔记时可创建「待办列表」类型；AI 助手能正确区分笔记本、碎片、待办三种笔记，不再往错误的笔记里写内容
- AI 助手支持用笔记标题定位，不必再抄一长串 ID；重名笔记会给出带序号的候选列表，用「标题 + 序号」重试即可选中，全程无需复述 ID
- 页面和待办项也支持按序号、标题或正文定位；工具报错会给出明确错误码和可操作建议，不再指向不存在的功能
- 云同步新增「扫描局域网服务器」：15 秒内自动发现同一 Wi-Fi 下的灵记服务端并填好地址与端口，扫描中可随时取消
- 云同步设置页显示本设备 ID，可一键复制、修改或重新生成；把两台设备的 ID 设为相同即可共用同一份笔记数据
- MiMo 模型新建配置时默认开启深度思考；多轮工具调用会完整保留思考内容，回答更连贯

## 优化

- 外接硬件键盘时，输入框聚焦与悬浮输入栏跟随键盘的行为更稳定，不再误触发页面跳动
- 弹窗内输入框不再被软键盘遮挡；下拉菜单定位、编辑器拖动时清除焦点等交互细节更稳
- 云同步改用版本号窗口判定增量数据：多台设备共用同一个设备 ID 时，也能互相拉到对方刚推送的内容
- 关闭深度思考或切换模型时自动清理历史思考内容，避免把不认识的字段发给其它模型接口

## 修复

- 修复向待办/笔记本笔记写碎片会「提示成功但笔记里永远看不到」的问题：现在明确拒绝，并能识别、清理历史遗留的孤立碎片
- 修复 AI 助手报错提示「请直接管理待办项」但工具集里根本没有对应能力的问题
- 修复页面工具误允许待办笔记写页面，以及文本替换在待办笔记上的错误提示
- 修复部分单元测试依赖本机特定路径、换台电脑就跑不起来的问题
